Screenshot Inserter Docs

Add test screenshots to Excel without moving or resizing them by hand.

01

Quick start

  1. Open test scenario sheet.
  2. Pick Test Type.
  3. Pick Evidence Type.
  4. Copy screenshot, then press Ctrl + V.
  5. Check preview.
  6. Select Insert.
  7. Wait for green success message.

02

Know the screen

Test Scenario

Shows test being updated. Open Condition or Expected Result when you need more detail.

Worksheet Status

PASS/FAIL means not final. Choose PASS or FAIL when result is known.

Evidence Type

Choose where screenshot belongs. General tests use Generic Screenshot.

Not loaded? Open correct scenario sheet, then select refresh button.

03

Paste a screenshot

  1. Copy PNG or JPEG screenshot.
  2. Click task pane.
  3. Press Ctrl + V.
  4. Check preview and file size.
  5. Select Insert.

Maximum size: 10 MB.

04

Use picture from another workbook

  1. Copy picture from source workbook.
  2. Open destination workbook.
  3. Paste picture onto scenario sheet.
  4. Select Use pasted Excel picture.
  5. Select picture you pasted.
  6. Check preview, then select Insert.

Temporary pasted picture is replaced after successful insertion.

05

Side and Header

These choices appear for Generic Screenshot.

Side

Left (A:D) places image on left. Right (F:I) places image on right.

Header

Add label for screenshot group. Same exact Header keeps matching screenshots together. Select Clear when no heading is needed.

06

Convert existing evidence

Use Convert Existing for headers and Excel picture objects that were already on the scenario sheet.

  1. Select one header cell or one header row in A:D or F:I.
  2. Select Convert Existing, then choose Header and pictures.
  3. Select Read selected header and verify the detected evidence type.
  4. Check the picture list, then select Convert Pictures.

Header only

Choose Header for next insertion to use the selected header once with the next screenshot.

User cells

Values, formulas, and unmanaged pictures in A:I stay untouched. New evidence continues below them with one blank row, while paired screenshots remain aligned.

Conversion changes only the pictures checked in the review list. Formatting alone does not block an otherwise empty header row.

07

Arrange existing evidence

Use Arrange Evidence when screenshot sections need different worksheet order.

  1. Load scenario and select correct Test Type.
  2. Select Arrange Evidence.
  3. Drag section by blue handle, or use ↑ and ↓.
  4. Check position numbers, then select Apply Arrangement.

Paired evidence

Sections marked Paired, such as PDF + AFP, move together and cannot be separated.

Return without applying

Select Back. If order changed, choose whether to discard changes or cancel Back.

Restore original order

Select Reset to chronological to return sections to insertion order.

Later screenshots

Saved order remains after insert or remove. New sections appear at end until rearranged.

Arrangement applies only to current worksheet, scenario, and Test Type.

08

Fix mistakes

Clear Pending

Use before insertion. Removes preview only.

Remove Last Inserted

Use after insertion. Removes latest screenshot added by tool.

Check scenario first. Remove works on scenario currently loaded.

09

Common problems

Scenario says “Not loaded”

Open scenario worksheet. If using Summary, select correct test row. Then select refresh button.

Paste does nothing

Copy screenshot again. Click task pane, then press Ctrl + V. Confirm image is PNG or JPEG.

Insert button is disabled

Check that scenario is loaded and screenshot preview is visible.

Excel picture is not detected

Paste picture onto destination worksheet first. Select Use pasted Excel picture, then select picture.

Wrong Side or Header

Remove wrong insertion. Change Side or Header, then insert again.
